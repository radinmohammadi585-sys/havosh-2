برنامه‌نویسی (آموزشی)

این بخش اجرای فایل C/C++ روی سرور انجام نمی‌دهد. آپلود و اجرای باینری روی سرور مدرسه خطرناک است. برای اسکن بدافزار از سرویس‌های معتبر مثل VirusTotal استفاده کنید.

مثال C — سلام دنیا

#include <stdio.h>

int main(void) {
    printf("Hello, Kavosh!\\n");
    return 0;
}

مثال C++ — جمع دو عدد

#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << (a + b) << endl;
    return 0;
}

یادداشت امنیتی

  • فایل‌های `.exe` / `.out` ناشناس را اجرا نکنید.
  • برای بررسی فایل مشکوک: VirusTotal
  • کد را در محیط محلی خودتان (با آنتی‌ویروس) یا Compiler Explorer تمرین کنید.
